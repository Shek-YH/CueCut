# CueCut 可商业使用动效素材候选清单

筛选日期：2026-09-07

筛选原则：仅保留来源明确且许可证明确允许商业使用、修改与再分发的素材；未读取或参考 Overlay Studio、LosslessCut、Olive 或其他竞品的源码、Schema、Prompt、UI、fixture 或素材。

## 结论

- 本批共 10 个候选，覆盖用户指定的 10 类。
- 9 个来自 Bootstrap Icons 官方仓库（MIT），1 个来自 Heroicons 官方仓库（MIT）。
- 全部为本地 SVG，透明背景，无字体、JavaScript、远程 URL 或运行时依赖。
- 不包含品牌 Logo、影视角色、明星肖像、商业模板或来源不明素材。
- 不包含把用户可替换标题/数字/字幕文字烘焙进图像的资产。
