## React Circular Progressbar
- GitHub: https://github.com/kevinsqi/react-circular-progressbar
- License: MIT
- Demo/README 提供圆形进度、dashboard/speedometer 等方案
- 本包没有直接复制其源码；作为第二候选参考。
- 原因：CueCut 视频渲染更适合 frame-driven 的 SVG RingMetric。

## 筛选原则
- 不纳入 Overlay Studio 源码、Schema、Prompt、UI 或素材。
- 不纳入许可证不明确项目。
- 不纳入当前已确认存在组件再分发限制的库。
- 第三方源码仅来自明确 MIT 项目并保留 License。
