# react-device-frameset Reference

Repository:
https://github.com/zheeeng/react-device-frameset

License:
MIT

Usefulness:
- mobile / tablet / laptop / browser presentation ideas
- device-frame composition patterns
- React-friendly wrapping of screenshots or videos

This v0.6 pack does not copy its source or branded device artwork.
CueCut-native `CueCutMobileDevice` and `CueCutLaptopMockup` are generic frames intended to avoid unnecessary dependency and trademarked device styling.

If Codex wants to integrate the library directly:
- preserve upstream MIT license
- inspect whether device-specific visual assets imply branded designs
- prefer generic CueCut skins for product-wide defaults
