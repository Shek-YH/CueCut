## Handoff summary

WI-003 implements the local watcher, atomic file writer, HTTP API, and SSE stream within the approved boundary.

Public entry points:

- `server/atomic.ts`: `atomicWriteFile` and `writeFileAtomically`.
- `server/watcher/index.ts`: `createLedgerWatcher`, `watchLedger`, debounce constants, and watcher lifecycle types.
- `server/api/index.ts`: `LedgerApi`, `ProjectRegistration`, and `SseHub`.
- `server/index.ts`: `createLedgerServer` plus the WI-003 exports.

`createLedgerServer({ projectRoots, port, debounceMs })` loads each supplied project through the WI-002 `LedgerStore`, starts a chokidar watcher for each project, and binds the Node HTTP server to `127.0.0.1` by default. Invalid reloads retain the store's Last Known Good snapshot and publish an SSE `error` frame.
