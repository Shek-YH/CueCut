## Scope delivered

- Added `POST /api/projects/:projectId/artifacts/open` to `LedgerApi`.
- Requires a registered project ID and JSON body `{ "path": "<relative artifact path>" }`.
- Resolves through `resolveContainedArtifactPath` before invoking the opener.
- Rejects empty, sensitive, traversal, absolute, and unknown-project inputs with clear JSON errors.
- Added an injectable `artifactOpener`; tests use a recorder and never launch Explorer.
- Windows default opener invokes `explorer.exe /select,<resolvedPath>`; non-Windows returns `501 PLATFORM_UNAVAILABLE`.
- Endpoint returns metadata only and does not serve file contents or write task state.
