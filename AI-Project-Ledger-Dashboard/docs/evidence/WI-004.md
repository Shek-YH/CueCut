## Scope

- Detects `.ai-ledger` and the WI-004 legacy Markdown filename allowlist.
- Maps `[x]` to `COMPLETED` and `[ ]` to `NOT_STARTED`.
- Maps only explicit `正在开发` / `进行中` / `阻塞` / `等待用户` phrases.
- Matches status phrases only at the start of a title with a conservative boundary, so embedded or negated text such as `未进行中的旧条目` remains unknown.
- Defaults unknown bullet status to `NOT_STARTED`, returns `LOW` confidence, and emits a warning.
- Creates a valid seven-file `.ai-ledger` skeleton or migrates legacy tasks additively.
- Existing `.ai-ledger` wins and is left untouched.
- Registry add/remove writes only the Dashboard registry file.
- Migration never deletes, moves, or rewrites source Markdown.
