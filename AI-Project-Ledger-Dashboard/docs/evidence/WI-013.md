# WI-013｜中文默认与中英文切换

## Scope

- Dashboard 默认语言为中文。
- 右上角提供中英文切换按钮。
- Overview、Tasks、Blockers、Activity、Roles、Artifacts、Settings 的界面文案、状态标签、筛选项、空状态、项目登记反馈和日期格式均随语言切换。
- 机器可读状态枚举、项目 ID、任务 ID、Agent 名称、事件类型、路径和只读数据边界保持不变。
