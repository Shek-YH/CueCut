## 一、包装层拆解（这条较弱，但仍有 4 个可学点）

本片主体是口播+屏录，包装密度低于 01/02，但仍有可取的组件：

1. **圆形人脸 PiP**：屏录画面左下角常驻圆形裁切的人脸小窗——讲软件时人不消失，保信任感。CueCut 教程类视频可直接用。
2. **开场 HUD 浮层**：人物四周环绕半透明数据卡片（仪表盘/进度条/统计卡），"人在信息中枢"的构图，3 秒立住"效率工具"人设。
3. **左右分屏对比**：`旧方案 Remotion skill（审美差/费token）‖ 新方法（先做卡片库）`，中间竖线分隔，上方标签常驻——比口述对比有力得多。
4. **底部字幕**：白色粗体无底板、带轻微阴影；简洁但依赖深色背景，浅色画面会吃力（01/02 的底条方案更稳）。

## 二、竞品拆解：他的工具架构（画面里直接抄下来的）

### 架构链路
```
剪映导出 SRT 字幕
  → Codex Skill《特效生成》（LLM 匹配）
  → overlay JSON {id, kind, start, end, x/y/w, fontSize, 文本内容}
  → Overlay Studio（本地网页编辑器，React+Vite）
      导入视频+JSON → 实时预览 → 拖拽改位置/大小微调
  → 导出透明背景视频：WebM(Alpha) 或 MOV(ProRes 4444)
  → 贴回剪映视频上方轨道
```

### 他的 Skill prompt 关键规则（屏录原文，逐字值得学）
1. **只能使用现有卡片库（必须严格遵守）**
2. 匹配根据内容去匹配；时间必须严格使用 SRT start/end，每个卡片绑定时间区间，可多卡同时存在但不能乱重叠
3. kind 必须是预定义 5 种之一
4. **严格禁止：不得创建新卡片类型、不得生成自定义UI组件、不得忽略时间戳、不得把所有内容塞进一个卡片、不得输出非JSON内容**
5. 视觉规则必须是"现在已经调试好的卡片"

### 他的工程细节（同样从屏录提取）
- 所有卡片重要文字（主数字/标题/对比内容/步骤文字/金句/图表数值/仪表盘文字）**统一加轻微阴影**——"更容易压在视频上看清"。
- 新卡片默认字号整体放大一档，拖进画布即可读。
- 编辑器左栏：卡片库列表（200+ 张、`小帅/小白` 标签分类、`左右对比` 等命名）；中间 1080P 预览画布；右栏参数。
- 导出决策树做成图卡：素材是黑底→WebM；要高质量→MOV ProRes 4444。

### 方法论（比架构更值钱）
| # | 原则 | 原话/依据 |
|---|---|---|
| 1 | **先做卡片库，再做软件** | "第一步我们先别着急做软件" |
| 2 | **卡片风格直接模仿对标**（只抄颜色/布局，不自己想） | "他的卡片风格很好看，只模仿他的颜色布局" |
| 3 | **少而精**：5–6 种卡片类型就够起量 | "正常五六个就够用" |
| 4 | **LLM 只做匹配，不做创作** | prompt 里三重禁止 |
| 5 | **嵌入剪映流程，不取代剪映** | 透明视频贴轨 |
| 6 | 先跑通再美化："第一版做的不好看，现在都改完了" | 迭代顺序：功能→样式 |

## 三、与 CueCut3 的逐条对照

| 维度 | 茂茂说AI（30分钟手搓版） | CueCut3 | 判定 |
|---|---|---|---|
| 链路 | SRT→LLM匹配→overlay JSON→透明视频导出 | SRT→PackagingPlan(Zod)→确定性帧求值→FFmpeg overlay/ProRes 4444/VP9 | **架构同构**，CueCut 更完整（统一 SceneFrame、预览导出同源） |
| 卡片数量 | 5–6 种精调 kind（库标称 200+） | 87 种，但 runtime 四档哈希降级 | **他少而精 vs 我多而糙**——01/02 号报告病因的竞品铁证 |
| LLM 约束 | prompt 三重禁止自由发挥 | PackagingPlan 有 constraints 字段但 prompt 层无"只能用现有卡片库"硬约束 | ❌ 需补 |
| 可读性 | 全卡片文字统一阴影+大字默认 | visualSurface 仅纯色块，无阴影/描边/底板 | ❌ 需补（此前 gap 分析 P1 已列） |
| 编辑体验 | 轻量本地网页，拖拽微调 | Electron 编辑器，更重 | 各有取舍，不追 |
| 导出 | WebM Alpha / MOV ProRes 4444 | ProRes 4444 / VP9 | 一致 ✅ |

**核心启示：一个 30 分钟手搓、只有 5-6 种卡片的工具，靠"精调样式 + LLM 硬约束 + 文字阴影"就能达到'审美在线'的口碑；CueCut 有 87 种卡片和更完整的管线，缺的正是这三件小事——这与三条参考视频归纳出的"渲染保真 + 系统层"病因完全一致。**
