## Downstream API for R03

```ts
import { evaluateMotionAdapterAtFrame } from './src/motions/adapters';

const model = evaluateMotionAdapterAtFrame({
  adapterId: 'number-ticker',
  frame: 30,
  fps: 30,
  role: 'enter',
  props: {
    common: { start: 0, duration: 2 },
    number: { value: 100, startValue: 0, decimalPlaces: 0, prefix: '', suffix: '' },
  },
});
// model.frame：opacity/translate/scale/rotation（blur 时含 blurPx）
// model.value / model.formattedValue：确定性数字状态
// model.text 或 model.items：确定性文字/列表状态
```
