## Implemented flow

```text
导入视频
→ 点击“开始生成动效”
→ 浏览器把视频发送到同源本地接口
→ Host FFmpeg 提取 16 kHz mono MP3
→ Alibaba Bailian qwen-audio-3.0-asr-flash 返回 timestamped SRT
→ Local Context Builder 注入 SRT、候选能力和 Preference Profile
→ 读取 CueCut_Director_SKILL.md
→ Director service 一次调用
→ Local Schema / Registry / timing validation and fallback
→ 生成 SRT + cuecut-composition JSON
→ 自动 replaceComposition 导入 Workspace
```

The Director Skill is used as the system behavior specification. The returned SRT is the transcript input; the browser sends the local structured Preference Profile in a request header, and the host includes it in the Director user context. The candidate index is bounded after local retrieval.

## Security and outputs

- The API key is read by the host middleware from the existing local env file and is never bundled into the browser or returned in JSON.
- User video is written only to a temporary host file and is deleted by the route's `finally` block.
- Generated SRT and composition files are written under the ignored `renders/` directory.
- After a successful generation, the normal generate button is disabled until a new video is imported, preventing an accidental second Director call.
