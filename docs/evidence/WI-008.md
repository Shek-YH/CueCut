## Attachment root cause

The supplied `F:\\CCPJ\\CueCut3\\renders\\jj-asr.srt` contained one block from `00:00:00,200` to `00:03:42,080` and one 1,085-character text line. The local `serializeSrt` function emits one block per input segment and does not merge segments. Alibaba's non-real-time API returns `output.sentence` as one sentence object for this model, with the finer timestamps in `output.sentence.words[]`; the previous adapter wrapped the sentence object as one segment and ignored `words[]`. The model was providing timing data, but the adapter discarded it. The adapter now groups words at terminal punctuation, a 4.5-second maximum, or 28 characters, while preserving each word's begin/end timestamps. See the provider's [non-real-time ASR API reference](https://help.aliyun.com/zh/model-studio/non-real-time-speech-recognition-for-fun-asr-flash).
