# AI Autonomous Project Ledger Skill v2.3.0 Architecture Upgrade Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the generic AI Autonomous Project Ledger Skill from v2.2.1 to v2.3.0 so non-trivial projects cannot declare completion without requirement evidence, independent verification, fidelity checks, and an explicit acceptance gate.

**Architecture:** Preserve the v2.2.1 seven-file Machine Ledger, shared read-only dashboard, Git Gate, Chinese/English UI, atomic writes, SSE, Last Known Good, and legacy compatibility. Add an optional `extensions/` control plane for non-trivial projects: requirements, verification, deviations, and model routing. Add generic Node-only validators and gates that read the core ledger plus extensions, while keeping domain-specific content in the project PRD and never in the Skill.

**Tech Stack:** Node.js built-ins, JSON schemas, Markdown templates, shared vanilla HTML/CSS/JavaScript dashboard, fixture-based regression tests.
